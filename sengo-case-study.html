Project Overview

Making city exploration effortless with SenGo

SenGo is a transit companion for tourists in Kyoto — designed to make public transport, complex fare rules, and real-time travel guidance feel understandable from the first screen.

Goals

  • Define a clear visual language — using color and typography to create a calm and approachable experience.
  • Build a design library from scratch — including color tokens, typography, and reusable UI components.
  • Design high-fidelity screens — using the library consistently across the whole app.
  • Test the core user flow — from route discovery and ticket purchase to navigation and route completion.
Visual Language

Archetype

The visual language is guided by the Caregiver archetype — supportive, calm, and trustworthy.

  • Blue carries the interactive layer with reliability.
  • Vermillion appears only where the user needs clear direction.
  • The layout avoids noise so the complexity of the transit system stays invisible.
  • SF Pro — readable at any size, no personality of its own.

Icons

Brand colour grounded in Kyoto's landmarks

The accent color was inspired by Kyoto's traditional torii gates. I chose vermilion because it is strongly associated with Japanese culture and creates a recognizable visual identity while remaining highly visible for important actions.

Core Flows

Home Discovery

A tourist doesn't just need a list of routes — they need to see where each one goes. Swiping through route cards highlights the path on the map above, so choosing a route is spatial.

Routes Catalogue

With seven transport types available, the list can get overwhelming fast. Filters let users narrow down by transport, difficulty, or duration — and selected filters stay visible so it's always clear what's being applied.

Routes Details & Buying Tickets

Before heading out, a tourist needs more details about route and buy their fare. All tickets for a multi-transport route can be purchased in one step — no switching between apps or screens.

Active Navigation

Once on the move, the priority shifts: less reading, faster access. All tickets for route are one tap away from the navigation screen — ready to show at the gate without searching.

Finish Route

Trip complete — time taken, sights visited, and a clear next action. The route can be saved or reversed for the return journey.

Usability Testing

Transport Filters

Testing the first prototype with real users revealed two major UX friction points in the route search process.

Users wanted to see their active filters on the main screen to know what filter they chose.

Checkbox states were hard to recognize, transport labels were hard to scan, and tap targets were too narrow.

Replaced the number badge with interactive chips that shows chosen filter inside instead of the label.

Result

A complete visual system and a tested end-to-end experience.

Built a reusable design library from scratch and used it across all high-fidelity screens. Testing with two participants revealed two usability issues, which were redesigned before delivery.
